# 💘 Valentine Mini Site

Interactive Valentine template built with pure HTML, CSS & JS.

## ✨ Features

- Animated Valentine hero
- Runaway "No" button logic
- Mini quiz with validation
- Image gallery with lightbox
- Love timer (since 06.10.2018)
- Music integration
- Smooth UI animations

## 🚀 Live Demo

👉 https://hryhoriy007.github.io/valentine-mini-site/

## 📦 How to use

1. Download ZIP
2. Open in VS Code
3. Replace:
   - Images
   - Music file
   - Love date
   - Letter text
4. Deploy or send to your partner 💞

## 🛠 Tech Stack

- HTML5
- CSS (Glass UI + animations)
- Vanilla JavaScript
